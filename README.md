# TaskFlow - Gestor de Tareas Minimalista

![TaskFlow Preview](https://img.shields.io/badge/Estado-Activo-success)
![Version](https://img.shields.io/badge/Versión-1.0.0-blue)
![Licencia](https://img.shields.io/badge/Licencia-MIT-green)

TaskFlow es una aplicación web minimalista y elegante para la gestión de tareas diarias, diseñada con un enfoque en la simplicidad y la eficiencia.

## ✨ Características

- 📱 Diseño responsivo y moderno
- 🌙 Modo oscuro por defecto
- 💾 Almacenamiento local de tareas
- ⭐ Marcado de tareas importantes
- 🔍 Filtrado de tareas por estado
- 🗑️ Gestión eficiente de tareas completadas
- ⚡ Animaciones suaves y profesionales

## 🚀 Tecnologías Utilizadas

- HTML5
- JavaScript (ES6+)
- Tailwind CSS
- Animate.css

## 🛠️ Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/MondoBoricua/TaskFlow.git
```

2. Navega al directorio del proyecto:
```bash
cd TaskFlow
```

3. Abre el archivo `index.html` en tu navegador preferido.

## 💡 Uso

1. **Agregar Tareas**
   - Escribe tu tarea en el campo de texto
   - Presiona Enter o haz clic en "Agregar"

2. **Gestionar Tareas**
   - ✓ Marca el círculo para completar una tarea
   - ⭐ Haz clic en la estrella para marcar como importante
   - 🗑️ Usa el icono de papelera para eliminar una tarea

3. **Filtrar Tareas**
   - Todas las tareas
   - Tareas activas
   - Tareas completadas
   - Tareas importantes

4. **Limpiar Tareas Completadas**
   - Usa el botón "Limpiar completadas" para eliminar todas las tareas finalizadas
